# Publish Bloom Together Mums on GitHub Pages

1. Extract the ZIP. Open index.html in your browser to preview the site. Keep styles.css and the assets folder alongside it.
2. Sign in at https://github.com and open https://github.com/new.
3. Create a repository named bloom-together-mums. Select Public and enable Add README so GitHub creates the main branch.
4. On the repository's Code tab, select Add file > Upload files.
5. Drag index.html, styles.css and the entire assets folder from File Explorer into the upload area. Use Chrome or Edge on your computer. Keep assets as a folder. You can also upload this README.
6. Check that index.html and styles.css are at the top level beside assets. Enter "Add Bloom Together Mums website" as the commit message and click Commit changes.
7. Open Settings > Pages. Under Build and deployment, choose Deploy from a branch. Select main and /(root), then click Save.
8. Check the Actions tab for the Pages deployment. Once it succeeds, return to Settings > Pages and choose Visit site. Your address will normally be https://YOUR-USERNAME.github.io/bloom-together-mums/.
9. Test the live site on your phone. Check that the photos load, the navigation works and the WhatsApp and email links open.

## Update your site

To edit text, open index.html in the repository, click the pencil, make your edits and click Commit changes. To change an image, upload its replacement to the assets folder using the same file name, including the same capitalisation. Changes to main trigger a new deployment.

## If something goes wrong

- 404: Check the Pages settings, the Actions run and that index.html is directly in the repository root.
- Missing photos or styling: Check that styles.css is beside index.html and the JPEGs are inside assets. Names are case-sensitive.

## Public information and hosting

Keep the repository for public website files. Store member registration, children's details, allergy information and volunteer records separately. GitHub Pages restricts use for running online businesses and e-commerce. This site is an informational community site.

Start with the free github.io address. If you control bloomtogethermums.co.uk and later want to connect it, follow GitHub's custom-domain guide. Preserve your existing email DNS records when making changes.
